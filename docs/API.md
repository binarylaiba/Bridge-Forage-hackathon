# Product Catalog API — Reference

| | |
|---|---|
| **Base URL** | `http://localhost:3001` |
| **Content-Type** | `application/json` |
| **Authentication** | None |

---

## GET /api/products

Returns the full list of products.

**Request body:** none

**Response body**

An array of `Product` objects.

| Field | Type | Description |
|---|---|---|
| `id` | string (uuid) | Auto-generated UUID v4 identifier. |
| `title` | string | Display name of the product. |
| `price` | number | Price of the product in dollars. |

**Status codes**

| Code | Meaning |
|---|---|
| `200 OK` | Array returned (may be empty). |

**curl example**

```bash
curl -s http://localhost:3001/api/products
```

---

## POST /api/products

Creates a new product. The server auto-generates the `id`.

**Request body**

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | ✓ | Display name of the product. |
| `price` | number | ✓ | Price of the product in dollars. |

**Response body**

The newly created `Product` object.

| Field | Type | Description |
|---|---|---|
| `id` | string (uuid) | Auto-generated UUID v4 identifier. |
| `title` | string | Display name of the product. |
| `price` | number | Price of the product in dollars. |

**Status codes**

| Code | Meaning |
|---|---|
| `201 Created` | Product created successfully. |

**curl example**

```bash
curl -s -X POST http://localhost:3001/api/products \
  -H "Content-Type: application/json" \
  -d '{"title":"Widget C","price":29.99}'
```

---

## PUT /api/products/{id}

Updates an existing product by its UUID. All writable fields are replaced with the values provided.

**Path parameters**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string (uuid) | ✓ | UUID v4 of the product to update. |

**Request body**

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | ✓ | New display name of the product. |
| `price` | number | ✓ | New price of the product in dollars. |

**Response body**

The updated `Product` object.

| Field | Type | Description |
|---|---|---|
| `id` | string (uuid) | UUID v4 identifier (unchanged). |
| `title` | string | Updated display name. |
| `price` | number | Updated price in dollars. |

**Status codes**

| Code | Meaning |
|---|---|
| `200 OK` | Product updated successfully. |
| `404 Not Found` | No product with the given `id` exists. |

**curl example**

```bash
curl -s -X PUT http://localhost:3001/api/products/<id> \
  -H "Content-Type: application/json" \
  -d '{"title":"Widget C Updated","price":39.99}'
```

---

## DELETE /api/products/{id}

Deletes a product by its UUID and returns the deleted record.

**Path parameters**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string (uuid) | ✓ | UUID v4 of the product to delete. |

**Request body:** none

**Response body**

The deleted `Product` object.

| Field | Type | Description |
|---|---|---|
| `id` | string (uuid) | UUID v4 identifier of the deleted product. |
| `title` | string | Display name of the deleted product. |
| `price` | number | Price of the deleted product in dollars. |

**Status codes**

| Code | Meaning |
|---|---|
| `200 OK` | Product deleted successfully. |
| `404 Not Found` | No product with the given `id` exists. |

**curl example**

```bash
curl -s -X DELETE http://localhost:3001/api/products/<id>
```

---

## Error Response

All `404` responses share a common error body.

| Field | Type | Description |
|---|---|---|
| `error` | string | Human-readable error message, e.g. `"Product not found"`. |

---

## Data Model

### Product

The full product object returned by the API.

| Field | Type | Read-only | Description |
|---|---|---|---|
| `id` | string (uuid v4) | ✓ | Auto-generated by the server on creation. Never accepted in request bodies. |
| `title` | string | — | Display name of the product. |
| `price` | number | — | Price of the product in dollars. |

### ProductInput

The shape accepted in request bodies for `POST` and `PUT`.

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | ✓ | Display name of the product. |
| `price` | number | ✓ | Price of the product in dollars. |
